# DDL-Fuga-do-labirinto
Jogo de labirinto para celular, criado para uma dinâmica de Banco de Dados sobre scripts DDL. Encontre a saída antes que o esquema mude: ALTER, DROP e CREATE transformam o mapa em tempo real. Os tempos são gravados em PostgreSQL (Supabase) e geram o ranking automático. HTML, CSS e JavaScript puros.
